# AcopioGT - Sistema de Gestión de Inventario y Acopio

### El sistema modela el acopio, almacenamiento, despacho y control de vencimientos de productos agrícolas y derivados utilizando herencia, interfaces y polimorfismo.

## Instrucciones de Compilación

### 1. Abra una terminal y ubíquese en la carpeta raíz donde se encuentran los archivos .java.
#### Esto se puede hacer poniendo cd y la dirección de la carpeta
### 2. Compile todos los archivos fuente utilizando el compilador de Java.
#### Con javac *.java
### 3. Después de compliar, corra el programa llamando a Main.
